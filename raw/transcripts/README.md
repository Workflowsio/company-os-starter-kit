# raw/transcripts

Recordings and call notes. One file per conversation.

**The test:** somebody was talking and something recorded it. Sales calls, client calls, internal meetings, interviews, voice memos, webinar recordings.

Name files `YYYY-MM-DD-who-what.md`, for example `2026-08-12-example-client-qbr.md`. Date first so the folder sorts chronologically, because this bucket grows faster than every other one combined.

**Not here:** a deck someone presented on the call goes in `../documents/`. A CSV they screen-shared goes in `../data-exports/`. Notes you typed up afterwards as a summary are already distilled, so they belong in `../../company-wiki/` or in the account's `operating-state.md`.

This bucket will end up holding almost everything in `raw/`. That is normal and it is exactly why the other buckets keep their READMEs: once transcripts are the only bucket anyone sees, the next person files an article here.
